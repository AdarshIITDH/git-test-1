# PHASE 8 — LEAVE APPROVAL WORKFLOW

Implement and validate the complete process.

### Employee

Employee selects leave dates and submits a request.

The application must:

- Check dates.
- Retrieve relevant policies.
- Calculate working days.
- Account for configured holidays.
- Verify employee identity.
- Save the request in SQLite as `PENDING`.
- Leave the employee's balance unchanged until approval.

### Manager

Manager opens the pending request.

AI should:

- Retrieve relevant leave policy from Milvus.
- Query HRMS leave balance through MCP.
- Check holiday calendar.
- Calculate eligible days.
- Explain whether the request appears compliant.
- Provide evidence and policy citations.

The manager must manually choose:

- Approve
- Reject

On approval:

- Update request status.
- Deduct correct leave days once.
- Record approving manager and timestamp.
- Update employee balance.
- Record audit history.

On rejection:

- Change request status.
- Do not deduct leave.
- Save manager decision.

Prevent duplicate approvals, unauthorized access, and double balance deductions.

AI must never approve a request automatically.
